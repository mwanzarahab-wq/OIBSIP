# To-Do Web App (OIBSIP · Web Development · Level 2 · Task 3)

A pastel "Today" widget-style to-do list built with vanilla HTML, CSS and JavaScript.

## Features
- Add tasks (optional time), appearing instantly in **Pending Tasks**
- Tick a task to move it to **Completed Tasks** (untick to move it back)
- Inline **Edit** (Enter to save, Esc to cancel) and permanent **Delete**
- Live counters: "X pending" and "Y completed"
- Timestamps for when a task was added and completed
- Persistence across refreshes with `localStorage`
- Friendly empty-state messages for both lists
- Gear button cycles four widget styles inspired by the design: grid paper, sticky note, rainbow rows, violet card
- Fully responsive: phones, tablets, laptops and large desktops (two-column lists on wide screens), plus landscape and notched-phone support
- Keyboard accessible

## Run it
Open `index.html` in any browser. No build step or dependencies.
