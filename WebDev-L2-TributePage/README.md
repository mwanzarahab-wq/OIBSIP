# Tribute Page: Ada Lovelace

Task 2 (Level 2) of the Oasis Infobyte Web Development & Designing internship.

A responsive tribute page honouring Ada Lovelace, widely regarded as the first computer programmer. Built with HTML5 and CSS3 only.

## Features
- Page title with the subject's name and a one-line tagline
- Prominent portrait (public domain, via Wikimedia Commons)
- Four-paragraph biography written in my own words
- Timeline of key moments in her life and legacy
- Distinctly styled quote block
- Four different section background colours
- Two font styles: Playfair Display (serif headings) and Source Sans 3 (sans-serif body)
- Fully responsive layout using CSS Grid and media queries

## Tech Stack
HTML5, CSS3
